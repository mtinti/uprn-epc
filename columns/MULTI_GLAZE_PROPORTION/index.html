    MULTI_GLAZE_PROPORTION¶

    As published. Publisher's label: Multiple Glazed Proportion.

    Publication note (page 15 under the label Multiple Glazed Proportion; quoted from the Scottish Government's note, SHA256 c2f336967e5d…, Open Government Licence v3.0): The estimated banded range (e.g. 0% - 10%) of the total glazed area of the Property that is multiple glazed.

    Group Type Nullable In the CSV SQL Server type
    published text no yes nvarchar(8) NOT NULL

    What was done to it¶

    copied. the cell's text exactly as published, trailing spaces and embedded newlines included; the empty string where the cell is empty (code: epc_ingest/reader.py: read_year)

    How it is checked¶

    What each check tests. Whether a build passed it is in that build's manifest.json["checks"], not here.

    • source.member: the annual file's SHA256 equals the pin in sources.yaml, so the bytes read are the bytes reviewed. Coverage: every byte of the file.
    • source.archive: the downloaded archive's SHA256 equals the pin; the build never reads the archive, only the extracted members. Coverage: every byte of the archive. Runs only under --verify-archive.
    • schema.matches_generator: output_schema.yaml is exactly what python -m epc_ingest.columns writes from published_columns.yaml and the derived list. Coverage: every field of the schema.
    • year.utf8: the annual file decodes as UTF-8 with no error. Coverage: every byte of the file.
    • year.header_names: the first header row equals the 107 pinned machine names, in order. Coverage: the header row.
    • year.header_labels: the second header row equals the 107 pinned labels, in order. Coverage: the header row.
    • year.row_width: every data row has 107 fields. Coverage: every row of the file.
    • year.text_within_width: no text value is longer than its column's declared nvarchar width. Coverage: every row of the file.
    • table.required_nonnull: every column the schema declares NOT NULL has no NULL. Coverage: every row of the table.
    • readback.parquet.rows: the saved Parquet has the rows the CSV has and one row group per annual file. Coverage: the whole file.
    • readback.parquet.digest: the row digest recomputed from the saved Parquet, rendered as the CSV renders it, equals the digest computed while writing the CSV, year by year. Coverage: every cell of every row.
    • readback.parquet.structure: the saved Parquet's columns, Arrow types and nullability are the schema's. Coverage: the schema of the file.
    • readback.parquet.sampled_rows_equal_source: for the first, middle and last row of every annual file, every published cell read back from the Parquet equals the raw text of the source file. Coverage: three rows per annual file (SAMPLE_ROWS), not every row; every row is covered by the digest.
    • readback.csv: the written CSV read back has the exported header, the row count and the digest total the build recorded. Coverage: every cell of every row.

    Why¶

    In force: values-as-published, derived-names-and-nullability, bounded-widths-max-in-digest, bulk-insert-codepage-utf8.

    In SQL Server¶

    Declared nvarchar(8) NOT NULL. Covered by the row digest that the loaded table is checked against.
