    Key and provenance columns¶

    Column Type Nullable Description
    epc_release text no The release of the extract this row came from, 2026Q2. A later release is a new build.
    source_year 16-bit integer no The annual file the row came from (2008 to 2026), which is the year of CREATED_AT.
    source_row 32-bit integer no 1 for the first data row of the file, which is file row 3 after the two header rows.

    Derived columns¶

    Column Type Nullable Description
    rrn text yes The report reference number as published where not empty, NULL where empty (9% of rows, mostly 2013 to 2016). Unique where present.
    uprn_sepcr 64-bit integer no The register's own 10-digit property reference, trimmed and as an integer. Not the Gazetteer UPRN. Present in every row.
    uprn_osg 64-bit integer yes The One Scotland Gazetteer UPRN as an integer, NULL where the published cell is empty (4.7% of rows). The only column a join compares; a padded cohort UPRN matches once cast to bigint.
    pc_norm text yes POSTCODE upper-cased with every space removed, postcode-simd's pc_norm. NULL where the published cell is empty. Nothing repaired.
    datazone_2001 text yes The 2001 data zone code when DATA_ZONE starts with S01 and six digits followed by a space or the end, otherwise NULL.
    datazone_2001_status text no code, empty, not_a_datazone (for 00Q, NA and the like) or unknown_code (well formed, not in the pinned list; the build fails if any).
    datazone_2011 text yes The 2011 data zone code by the same rule, otherwise NULL.
    datazone_2011_status text no As datazone_2001_status, for the 2011 column.
    inspection_date_parsed date no INSPECTION_DATE (yyyy-mm-dd) as a date: the day the assessor saw the dwelling. The dated joins choose the certificate by it. A value that does not parse stops the build.
    lodgement_date_parsed date no LODGEMENT_DATE (yyyy-mm-dd) as a date. The administrative date of the certificate, the same day as the inspection or soon after (median 1 day); the ten-year validity runs from it. Outliers (2002, 2006, 2108) are kept as published.
    created_at_parsed timestamp no CREATED_AT (dd/mm/yyyy hh:mm:ss) as a timestamp to the second. Its year is the file year.
    historic_flag flag no 1 where HISTORIC is True (the certificate has been superseded), 0 where False. Any other value stops the build.
    current_energy_efficiency_int 32-bit integer no The current energy efficiency rating as an integer. A SAP rating runs 1 to 100; values above 100 are publisher errors kept as published and counted in the build report.
    potential_energy_efficiency_int 32-bit integer no The potential energy efficiency rating as an integer.
    environment_impact_current_int 32-bit integer no The current environmental impact rating as an integer.
    environment_impact_potential_int 32-bit integer no The potential environmental impact rating as an integer.
    total_floor_area_int 32-bit integer no Total floor area in square metres as an integer. 0 in every 2008 and 2009 row.
    energy_consumption_current_num decimal(19,4) no Primary energy indicator (kWh per square metre per year) as decimal(19,4).
    co2_emissions_current_num decimal(19,4) no Current emissions (tonnes of CO2 per year) as decimal(19,4).
    co2_emiss_curr_per_floor_area_num decimal(19,4) no Current emissions per floor area (kg of CO2 per square metre per year) as decimal(19,4).
