    Checks¶

    Every check the build can emit, by family (epc_ingest/check_catalogue.yaml). Each is blocking: a failure stops the build and nothing is promoted. A build's manifest records which were emitted and their results; this page defines them and says how far each reaches.

    source.member¶

    Name pattern ^source\.[^/]+/extracted/\d{4}\.csv$. The annual file's SHA256 equals the pin in sources.yaml, so the bytes read are the bytes reviewed.

    Applies to every column. Coverage: every byte of the file. Runs in every build.

    source.datazone_list¶

    Name pattern ^source\.datazones/. The data zone reference list's SHA256 equals the pin, the same hash the sibling project pins.

    Applies to datazone_2001, datazone_2001_status, datazone_2011, datazone_2011_status. Coverage: every byte of the list. Runs in every build.

    source.archive¶

    Name pattern ^source\.[^/]+/[^/]+\.7z$. The downloaded archive's SHA256 equals the pin; the build never reads the archive, only the extracted members.

    Applies to every column. Coverage: every byte of the archive. Runs only under --verify-archive.

    source.note¶

    Name pattern ^source\.[^/]+/publication_note\.pdf$. The publication note's SHA256 equals the pin; the note is documentation, the source of the column descriptions.

    Applies to no column: table-level. Coverage: every byte of the note. Runs only under --verify-archive.

    schema.matches_generator¶

    Name pattern ^schema\.matches_generator$. Output_schema.yaml is exactly what python -m epc_ingest.columns writes from published_columns.yaml and the derived list.

    Applies to every column. Coverage: every field of the schema. Runs in every build.

    datazones.count¶

    Name pattern ^datazones_\d{4}\.count$. The reference list holds the pinned number of zones.

    Applies to datazone_2001, datazone_2001_status, datazone_2011, datazone_2011_status. Coverage: the whole list. Runs in every build.

    datazones.distinct¶

    Name pattern ^datazones_\d{4}\.distinct$. No zone code repeats in the reference list.

    Applies to datazone_2001, datazone_2001_status, datazone_2011, datazone_2011_status. Coverage: the whole list. Runs in every build.

    year.utf8¶

    Name pattern ^\d{4}\.utf8$. The annual file decodes as UTF-8 with no error.

    Applies to every published column. Coverage: every byte of the file. Runs in every build.

    year.header_names¶

    Name pattern ^\d{4}\.header_names$. The first header row equals the 107 pinned machine names, in order.

    Applies to every published column. Coverage: the header row. Runs in every build.

    year.header_labels¶

    Name pattern ^\d{4}\.header_labels$. The second header row equals the 107 pinned labels, in order.

    Applies to every published column. Coverage: the header row. Runs in every build.

    year.row_width¶

    Name pattern ^\d{4}\.row_width$. Every data row has 107 fields.

    Applies to every published column. Coverage: every row of the file. Runs in every build.

    year.rows¶

    Name pattern ^\d{4}\.rows$. The number of data rows equals the pin for the member, so source_row runs 1 to that number.

    Applies to source_year, source_row. Coverage: every row of the file. Runs in every build.

    year.rrn_shape¶

    Name pattern ^\d{4}\.rrn_shape$. Every non-empty REPORT_REFERENCE_NUMBER has the shape 9999-9999-9999-9999-9999.

    Applies to rrn. Coverage: every row of the file. Runs in every build.

    year.rrn_unique_in_file¶

    Name pattern ^\d{4}\.rrn_unique_in_file$. No non-empty REPORT_REFERENCE_NUMBER repeats within the file.

    Applies to rrn. Coverage: every row of the file. Runs in every build.

    year.created_at_year¶

    Name pattern ^\d{4}\.created_at_year$. Every CREATED_AT falls in the file's year, the rule that places a row in its annual file.

    Applies to source_year, created_at_parsed. Coverage: every row of the file. Runs in every build.

    year.derived_values_parse¶

    Name pattern ^\d{4}\.derived_values_parse$. Every date, timestamp, flag, integer and decimal a derived column needs parses by its rule; one failure stops the build.

    Applies to uprn_sepcr, uprn_osg, inspection_date_parsed, lodgement_date_parsed, created_at_parsed, historic_flag, current_energy_efficiency_int, potential_energy_efficiency_int, environment_impact_current_int, environment_impact_potential_int, total_floor_area_int, energy_consumption_current_num, co2_emissions_current_num, co2_emiss_curr_per_floor_area_num. Coverage: every row of the file. Runs in every build.

    year.text_within_width¶

    Name pattern ^\d{4}\.text_within_width$. No text value is longer than its column's declared nvarchar width.

    Applies to every string column. Coverage: every row of the file. Runs in every build.

    year.decimal_round_trip¶

    Name pattern ^\d{4}\.decimal_round_trip$. Every decimal cell survives file text to Decimal to 4-place text to Decimal unchanged, so the CSV, the digest and SQL Server agree to the byte.

    Applies to energy_consumption_current_num, co2_emissions_current_num, co2_emiss_curr_per_floor_area_num. Coverage: every row of the file. Runs in every build.

    table.rows¶

    Name pattern ^table\.rows$. The key (epc_release, source_year, source_row) is unique over the whole table.

    Applies to every key column. Coverage: every row of the table. Runs in every build.

    table.rrn_unique¶

    Name pattern ^table\.rrn_unique$. No rrn repeats across the whole table.

    Applies to rrn. Coverage: every row of the table. Runs in every build.

    table.uprn_one_to_one¶

    Name pattern ^table\.uprn_one_to_one$. Each uprn_osg maps to one uprn_sepcr and each uprn_sepcr to one uprn_osg, where both exist.

    Applies to uprn_osg, uprn_sepcr. Coverage: every row of the table. Runs in every build.

    table.no_unknown_code¶

    Name pattern ^table\.datazone_\d{4}_status\.no_unknown_code$. No well-formed data zone code is absent from the vintage's reference list.

    Applies to datazone_2001, datazone_2001_status, datazone_2011, datazone_2011_status. Coverage: every row of the table. Runs in every build.

    table.required_nonnull¶

    Name pattern ^table\.required_nonnull$. Every column the schema declares NOT NULL has no NULL.

    Applies to every nonnull column. Coverage: every row of the table. Runs in every build.

    readback.parquet.rows¶

    Name pattern ^readback\.parquet\.(rows|row_groups)$. The saved Parquet has the rows the CSV has and one row group per annual file.

    Applies to every column. Coverage: the whole file. Runs in every build.

    readback.parquet.digest¶

    Name pattern ^readback\.parquet\.\d{4}\.digest$. The row digest recomputed from the saved Parquet, rendered as the CSV renders it, equals the digest computed while writing the CSV, year by year.

    Applies to every exported column. Coverage: every cell of every row. Runs in every build.

    readback.parquet.one_year_per_row_group¶

    Name pattern ^readback\.parquet\.\d{4}\.one_year_per_row_group$. Each row group holds one source_year.

    Applies to source_year. Coverage: every row of the table. Runs in every build.

    readback.parquet.structure¶

    Name pattern ^readback\.parquet\.(column_names|column_types|nullability)$. The saved Parquet's columns, Arrow types and nullability are the schema's.

    Applies to every column. Coverage: the schema of the file. Runs in every build.

    readback.parquet.metadata¶

    Name pattern ^readback\.parquet\.metadata\.. The saved Parquet carries the build's grain, key, schema version, release, source pins and the hashes of the registry and the decision log.

    Applies to no column: table-level. Coverage: the file's metadata. Runs in every build.

    readback.parquet.sampled_rows_equal_source¶

    Name pattern ^readback\.parquet\.sampled_rows_equal_source$. For the first, middle and last row of every annual file, every published cell read back from the Parquet equals the raw text of the source file.

    Applies to every published column. Coverage: three rows per annual file (SAMPLE_ROWS), not every row; every row is covered by the digest. Runs in every build.

    readback.csv¶

    Name pattern ^readback\.csv\.(header|rows|digest_total)$. The written CSV read back has the exported header, the row count and the digest total the build recorded.

    Applies to every exported column. Coverage: every cell of every row. Runs in every build.
